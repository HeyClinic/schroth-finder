# Schroth PT Finder

Hey Clinic's map for showing patients the closest Schroth physical therapy location. Live at https://210avedis-star.github.io/schroth-finder/

`index.html` is one self-contained page built by `python3 build.py` from `src/index.src.html`, `src/sites.json` (the clinic list), `src/zips.txt` (US cities and ZIPs) and `src/heyclinic-logo.png`. Nothing a patient types is saved.
